## 🌟 The 8 Pure-Python Geospatial SDKs

| SDK Package | PyPI Link | Documentation (`github.io`) | Primary Capabilities |
| :--- | :--- | :--- | :--- |
| **`geoai2analytics-sdk`** | [![PyPI](https://img.shields.io/pypi/v/geoai2analytics-sdk)](https://pypi.org/project/geoai2analytics-sdk/) | [geoai2analytics Manual](https://geophilo.com/geoai2analytics-sdk/) | 81 spatial statistics & econometrics algorithms, Moran's I, LISA, GWR/MGWR, Spatial SHAP. |
| **`multilayer-sdk`** | [![PyPI](https://img.shields.io/pypi/v/multilayer-sdk)](https://pypi.org/project/multilayer-sdk/) | [multilayer-sdk Studio](https://geophilo.com/multilayer-sdk/) | Synchronized 2-8 panel map grids, real-time laser crosshairs, curtain swipe changer. |
| **`myface2city`** | [![PyPI](https://img.shields.io/pypi/v/myface2city)](https://pypi.org/project/myface2city/) | [MyFace2City Studio](https://geophilo.com/myface2city/) | Optical urban portrait engine, variable-radius vector stippling, OSM client, SVG exporter. |
| **`NCZ2Geo`** | [![PyPI](https://img.shields.io/pypi/v/NCZ2Geo)](https://pypi.org/project/NCZ2Geo/) | [NCZ2Geo Manual](https://geophilo.com/NCZ2Geo/) | Proprietary Netcad NCZ/NCA parser, PlanGML zoning identity, official e-Plan symbology. |
| **`cad2geo`** | [![PyPI](https://img.shields.io/pypi/v/cad2geo)](https://pypi.org/project/cad2geo/) | [cad2geo Manual](https://geophilo.com/cad2geo/) | High-speed binary CAD block decompressor, coordinate reprojector, and GeoJSON engine. |
| **`osm2threejs`** | [![PyPI](https://img.shields.io/pypi/v/osm2threejs)](https://pypi.org/project/osm2threejs/) | [osm2threejs Studio](https://geophilo.com/osm2threejs/) | Headless 3D procedural city generation into Three.js WebGL scenes, glTF/GLB & OBJ. |
| **`zero2route3d_sdk`** | [![PyPI](https://img.shields.io/pypi/v/zero2route3d_sdk)](https://pypi.org/project/zero2route3d_sdk/) | [zero2route3d Manual](https://geophilo.com/zero2route3d_sdk/) | 3D DEM slope kinematics, Minetti metabolic energy routing, HMM Viterbi map-matching. |
| **`planx_sdk`** | [![PyPI](https://img.shields.io/pypi/v/planx_sdk)](https://pypi.org/project/planx_sdk/) | [planx_sdk Manual](https://geophilo.com/planx_sdk/) | Spatial planning MCDA (AHP/TOPSIS), 28 urban resilience indices, cellular automata. |

## ⚡ Quick Multi-Install Command

```bash
pip install geoai2analytics-sdk multilayer-sdk myface2city NCZ2Geo cad2geo osm2threejs zero2route3d_sdk planx_sdk
```
